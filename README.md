# Mealify - Restaurant Landing Page  

## 🚀 Live Demo  
[View Project](https://o-marss.github.io/mealify-task/)  

## 📌 About  
**Mealify** is a modern and stylish restaurant landing page designed to showcase a restaurant’s menu, services, and contact information. The website features a clean layout with a responsive design and a dark mode toggle for a better user experience.  

## 🛠️ Built With  
- **HTML5** - For structuring the content.  
- **CSS3** - For styling and layout.  
- **Flexbox** - For creating a flexible and responsive layout, ensuring proper alignment and spacing across different screen sizes.  
- **CSS Variables** - Used to efficiently manage the light and dark mode toggle, making it easy to switch themes dynamically.  

## 🎨 Features  
- Fully responsive design for all screen sizes.  
- Dark mode toggle using CSS variables for seamless theme switching.  
- Modern and elegant restaurant-themed UI.  
- Smooth scrolling and clean layout.
